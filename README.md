# Habla con Luti

Práctica oral del manual **Inglés A1 · Nivel básico** (LUTIMOCA): escucha, repite, contesta en voz alta y recibe corrección de pronunciación.

**Abrir la app:** https://nanoeskala-luti.github.io/ingles-a1/

- Ábrela en **Chrome** (Android) o **Safari** (iPhone) y permite el micrófono cuando lo pida.
- Necesitas el **código del mes** que te da tu maestro. Tu avance se queda guardado en tu teléfono.

---
Para actualizar: la página se publica desde la rama `gh-pages`. Sube cada cambio a `main` y a `gh-pages`.
